## はじめに

**MediaForge** へようこそ。MediaForge はデスクトップ向けのビジュアル FFmpeg ワークフローアプリです。動画の書き出し、GIF 作成、音声抽出、画像処理、カスタム FFmpeg コマンドなどを、主にご自身のデバイス上で行えます。

本プライバシーポリシーは、MediaForge アプリ、[mediaforgeapp.com](https://www.mediaforgeapp.com) のウェブサイト、および関連サービス（総称して「本サービス」）の利用時に収集する情報について説明します。**MediaForge Open はローカルでのメディア処理を前提**としており、プライバシーを重視しています。

## 適用範囲

本ポリシーの対象：

- **MediaForge Open** — [GitHub Releases](https://github.com/mediaforgeapp/mediaforge/releases) から入手できる無料のオープンソース版
- **公式ウェブサイト** — 製品情報、ダウンロード、サポート
- **将来の MediaForge Pro 機能** — AI Forge、拡張プリセット、有料サブスクリプションなど。アカウントやクラウド連携を伴う Pro 機能の提供前に本ポリシーを更新します。

## MediaForge Open — デフォルトはローカル

現行のオープンソース版では、**ローカル処理**が中心です。

### デバイス上に残るもの

- **入出力ファイル** — 動画・音声・画像などは端末上で処理され、当社サーバーには保存しません。
- **FFmpeg の実行** — 端末上の FFmpeg / FFprobe によりローカルで変換します。
- **アプリ設定** — UI 言語など、デバイスに保存される設定。
- **ワークフローデータ** — プリセット、最近のタスク、メタデータなどがローカルに保存される場合があります。

### 現行 Open 版が当社に収集しないもの

MediaForge Open は**アカウント不要**で、現状**以下を行いません**：

- クリップボード内容の収集
- メディアやプロジェクトデータの当社サーバーへの同期
- 必須のインナー分析やクラッシュレポートの送信
- ファイル名や内容の自動送信

アプリ内リンク（GitHub や公式サイトなど）は、ブラウザまたは OS が個別に処理します。

### ユーザーの責任

処理するファイルと出力先はユーザーが選択します。デバイスのセキュリティ、バックアップ、権利のあるメディアの利用についてはユーザーが責任を負います。

## ウェブサイト

[mediaforgeapp.com](https://www.mediaforgeapp.com) 訪問時、サイト運営・改善に必要な限定的な情報を収集する場合があります。

### 収集し得る情報

1. **連絡先** — [support@mediaforgeapp.com](mailto:support@mediaforgeapp.com) へのメール内容（返信のため）。
2. **利用・デバイス情報** — 分析ツール（有効な場合の Vercel Analytics や Google Analytics など）によるトラフィック把握。個人情報の販売は行いません。
3. **Cookie** — 基本機能、言語、分析のため。ブラウザ設定で制限可能。

### ダウンロードページ

GitHub Releases からのダウンロードは GitHub が提供します。ダウンロード自体により当社がメディアやアプリ利用データを受け取ることはありません。

## 将来の MediaForge Pro

有料またはアカウント連携の Pro 機能を提供する場合、更新されたポリシーでデータ取扱いを説明します。Pro は任意で、Open のローカルワークフローとは独立します。

## 第三者サービス

FFmpeg / FFprobe、GitHub、ウェブ分析（有効時）、将来の決済処理など。各提供者は独自のポリシーに従います。

## 保存とセキュリティ

合理的な保護措置を講じますが、完全な安全は保証できません。Open 版では端末上の保護が最も重要です。

## 情報の共有

個人情報を販売しません。同意、機密義務のある委託先、法令に基づく場合に限り共有することがあります。

## お客様の権利

居住地の法律に応じ、アクセス・訂正・削除・制限を請求できる場合があります。Open のローカルデータはアプリ削除や出力ファイルの削除で除去できます。

お問い合わせ：[support@mediaforgeapp.com](mailto:support@mediaforgeapp.com)。

本サービスは 13 歳未満（または適用法の最低年齢未満）を対象としません。
