## 소개

**MediaForge**에 오신 것을 환영합니다. MediaForge는 데스크톱용 시각적 FFmpeg 워크플로 앱으로, 동영상보내기, GIF 만들기, 오디오 추출, 이미지 처리, 사용자 지정 FFmpeg 명령 등을 주로 사용자 기기에서 수행합니다.

본 개인정보 처리방침은 MediaForge 앱, [mediaforgeapp.com](https://www.mediaforgeapp.com) 웹사이트 및 관련 서비스(통칭 «서비스») 이용 시 수집하는 정보를 설명합니다. **MediaForge Open은 로컬 미디어 처리를 전제**로 하며 개인정보를 중요하게 생각합니다.

## 적용 범위

본 방침의 대상:

- **MediaForge Open** — [GitHub Releases](https://github.com/mediaforgeapp/mediaforge/releases)의 무료 오픈소스 데스크톱 앱
- **공식 웹사이트** — 제품 정보, 다운로드, 지원
- **향후 MediaForge Pro 기능** — AI Forge, 확장 프리셋, 유료 구독 등. 계정 또는 클라우드 연동 Pro 기능 출시 전 본 방침을 업데이트합니다.

## MediaForge Open — 기본은 로컬

현재 오픈소스 버전은 **로컬 처리**를 중심으로 합니다.

### 기기에 남는 데이터

- **입·출력 파일** — 동영상, 오디오, 이미지 등은 기기에서 처리되며 당사 서버에 저장하지 않습니다.
- **FFmpeg 실행** — 기기의 FFmpeg / FFprobe로 로컬 변환합니다.
- **앱 설정** — UI 언어 등 기기에 저장되는 환경설정.
- **워크플로 데이터** — 프리셋, 최근 작업, 메타데이터가 로컬에 저장될 수 있습니다.

### 현재 Open 버전이 수집하지 않는 항목

MediaForge Open은 **계정이 필요 없으며**, 현재 형태에서 **다음을 하지 않습니다**:

- 클립보드 내용 수집
- 미디어·프로젝트 데이터의 당사 서버 동기화
- 필수 인앱 분석·크래시 리포트 전송
- 파일명·내용의 자동 전송

앱 내 링크(GitHub, 웹사이트 등)는 브라우저 또는 OS가 별도로 처리합니다.

### 사용자 책임

처리할 파일과 출력 위치는 사용자가 선택합니다. 기기 보안, 백업, 권리 있는 미디어 사용 준수는 사용자 책임입니다.

## 웹사이트

[mediaforgeapp.com](https://www.mediaforgeapp.com) 방문 시 사이트 운영·개선에 필요한 제한적 정보를 수집할 수 있습니다.

### 수집 가능 정보

1. **연락처** — [support@mediaforgeapp.com](mailto:support@mediaforgeapp.com) 이메일 내용(회신 목적).
2. **이용·기기 정보** — 분석 도구(활성화 시 Vercel Analytics, Google Analytics 등)로 트래픽 파악. 개인정보 판매 없음.
3. **쿠키** — 기본 기능, 언어, 분석용. 브라우저에서 제한 가능.

### 다운로드 페이지

GitHub Releases 다운로드는 GitHub가 제공합니다. 다운로드 과정 자체로 당사가 미디어·앱 사용 데이터를 받지 않습니다.

## 향후 MediaForge Pro

유료 또는 계정 기반 Pro 기능 제공 시 업데이트된 방침에서 데이터 처리를 설명합니다. Pro는 선택 사항이며 Open의 로컬 워크플로와 별개입니다.

## 제3자 서비스

FFmpeg / FFprobe, GitHub, 웹 분석(활성화 시), 향후 결제 처리 등. 각 제공자는 자체 정책을 따릅니다.

## 보관 및 보안

합리적 보호 조치를 적용하나 절대적 안전은 보장하지 않습니다. Open 버전에서는 기기 보호가 가장 중요합니다.

## 정보 공유

개인정보를 판매하지 않습니다. 동의, 비밀 유지 의무가 있는 위탁업체, 법적 요구 시에만 공유할 수 있습니다.

## 이용자 권리

거주 지역 법에 따라 열람·정정·삭제·제한을 요청할 수 있습니다. Open 로컬 데이터는 앱 삭제 또는 출력 파일 삭제로 제거할 수 있습니다.

문의: [support@mediaforgeapp.com](mailto:support@mediaforgeapp.com).
